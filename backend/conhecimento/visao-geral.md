# Recife Por Elas

Recife Por Elas conecta maes e mulheres do Recife a oportunidades de trabalho, cursos, beneficios sociais e uma rede de apoio comunitaria.

## Como usar

1. Crie uma conta e complete o perfil com bairro, rotina e interesses.
2. Consulte o Feed para filtrar oportunidades por tipo.
3. Use o Mapa para encontrar pontos de referencia e servicos.
4. Abra o Plano de carreira para responder o questionario e receber uma trilha personalizada.
5. Use a Rede de Apoio para publicar, pedir ajuda, comentar e curtir dentro da comunidade.

As oportunidades exibidas devem vir das fontes cadastradas no sistema. Quando uma informacao nao estiver disponivel, a assistente deve dizer isso claramente.
